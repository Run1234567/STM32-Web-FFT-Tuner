# 🚀 STM32-Web-FFT-Tuner

一个基于 **STM32 DSP 库**与 **Web Serial API** 实现的高性能实时频谱分析仪与音调识别系统。

## 🌟 项目亮点

* **极速通信**：采用 `1,152,000` 超高波特率，实现丝滑的 60FPS 频谱刷新率。
* **精准对齐**：独创 `START` 帧同步机制，彻底解决串口丢包导致的“频率漂移”和“画面错位”问题。
* **硬核计算**：利用 STM32 硬件浮点单元 (FPU) 与 CMSIS-DSP 库执行 **1024 点 CFFT**，运算时间微秒级。
* **音调侦测**：内置频率转音名算法，支持 **C0 - B8** 全频段音调识别，实时显示当前主音（如 A4, C#5）。
* **零安装成本**：基于 Web Serial API，无需下载任何串口助手，直接在 Chrome 浏览器打开 HTML 即可运行。

---

## 🛠️ 技术栈

### 下位机 (STM32)

* **ADC + DMA**：高速采集音频原始波形。
* **DSP Lib (CMSIS)**：执行实部/虚部转换及 `arm_cfft_f32` 运算。
* **UART**：高速数据打包外发。

### 上位机 (HTML5 / JavaScript)

* **Web Serial API**：浏览器原生串口通信。
* **Canvas API**：高性能 HSL 彩虹渐变频谱渲染。
* **Music Theory Logic**：基于对数公式 **\$n = 12 \\times \\log\_2(f / 440) + 69\$** 的音调转换。

## 📖 项目深度解析 (How it works)

### 这个项目是干什么的？

这是一个**软硬结合的音频分析系统**。它能实时捕获外界的声音，并像“手术刀”一样将复杂的声波拆解开来。

* **对于工程师**：它是一个低成本的串口频谱分析仪，可以用来调试滤波器或观测信号特征。
* **对于音乐人**：它是一个高精度的数字调音器，能瞬间告诉你当前声音的物理频率以及对应的乐理音名（如 C4、A4）。

---

### 它是怎么做到的？ (技术细节)

系统的实现可以拆解为以下三个核心阶段：

#### 1. 采集与信号处理 (STM32 端)

单片机扮演的是“高性能传感器”的角色：

* **ADC 采样**：通过定时器触发 ADC，以 **10,000Hz** 的频率对麦克风输出的模拟电压进行采样。这意味着它每秒钟记录 10,000 个电压值，能够捕获最高 5,000Hz 的声音（奈奎斯特采样定律）。
* **直流偏置消除**：原始信号通常叠加在 1.5V 的直流电平上，代码通过减去常数（1500）让信号回到 0 轴上下震荡。
* **硬核 FFT 运算**：
  * 调用 **ARM CMSIS-DSP** 库中的浮点运算函数。
  * 将时域的电压波动转换为频域的幅值分布。
  * 得到 1024 个频率点（Bin），每个点代表一段特定频率范围的强度。

#### 2. 帧同步传输协议 (通信层)

由于波特率高达 **1,152,000 bps**，数据传输极快，单字节丢失会导致后续波形乱码。

* **START 令牌机制**：单片机在每发送 512 个频谱数据前，先发送一个字符串 `"START\n"`。
* **网页端自动纠错**：JavaScript 在接收数据时，只要检测到 `START` 关键字，就会强行重置数据指针。即使串口线受到电磁干扰丢包，系统也能在毫秒内自动恢复对齐，**确保 0Hz 的柱子永远在画布最左侧，绝不平移滑动。**

#### 3. 视觉渲染与乐理映射 (Web 浏览器端)

浏览器扮演的是“仪表盘”的角色：

* **Canvas 高效绘图**：利用 HTML5 Canvas 逐帧绘制 512 根柱子。柱子的高度代表能量，颜色根据频率从低到高映射为红->紫的彩虹色（HSL 颜色空间）。
* **主频搜索算法**：在 512 个点中寻找能量最强（幅值最大）的索引值 `maxIndex`。
* **音调识别逻辑**：
  1. 计算物理频率：**\$f = maxIndex \\times \\frac{10000}{1024}\$**。
  2. 对数映射音阶：根据半音音阶公式，将物理频率转换为 MIDI 编号，再通过 `index % 12` 映射到 `[C, C#, D, D#, E, F, F#, G, G#, A, A#, B]` 十二平均律音名中。

## 📦 快速开始

### 1. 硬件连接

1. 将麦克风模块（如 MAX9814）连接至 STM32 的 ADC 引脚。
2. 使用 USB-TTL 模块连接单片机串口与电脑。

### 2. 打开网页

1. 使用 Chrome 或 Edge 浏览器打开项目中的 `index.html`。
2. 点击 **“连接单片机”**，选择对应的 COM 口。
3. 调大网页上的 **“灵敏度”** 滑块，观察频谱跳动。

## 📊 性能参数


| **参数**                | **数值**      | **备注**                        |
| ----------------------- | ------------- | ------------------------------- |
| 采样频率 (**\$F\_s\$**) | 10,000 Hz     | 支持最高 5,000 Hz 音频分析      |

| 刷新率                  | \~10 Hz       | 受限于单片机`delay_ms(100)`设置 |
| 波特率                  | 1,152,000 bps | 极速传输，拒绝延迟              |
